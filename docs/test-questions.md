# 测试提问清单（覆盖主链路）

## A. 基础准确性
1. 标准版和专业版分别多少钱？
2. 企业版试用政策是什么？
3. 关键故障响应时间是多久？
4. 审计日志保存多久？

## B. 多字段组合
5. 请同时告诉我：企业版价格、SLA 目标、技术支持邮箱。
6. 哪些角色可以删除文档？谁可以导出完整审计日志？

## C. 反幻觉（应拒答）
7. 星舟智能支持离线私有化部署吗？
8. 是否支持自动解析扫描版图片中的小语种文字？
9. 企业版支持 7 天无理由退款吗？

## D. 越权/不存在信息（应回复“文档中未提及相关信息。”）
10. 公司的北京办公室地址是什么？
11. NebulaInsight 的 API 限流默认值是多少？
12. 支持 WhatsApp 客服吗？

## E. Prompt 与实验参数联动
13. 把回答改成“结论 + 依据”的格式（验证 Prompt 生效）。
14. topK 从 3 调到 8，回答是否更完整？
15. 阈值从 0.4 调到 0.7，是否更容易出现“未提及”？
